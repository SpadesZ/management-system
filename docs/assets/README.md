# Screenshot source

`admin-approvals.png` was captured from this checkout's Vue UI and FastAPI backend on an isolated local database. Login used the repository seed admin. The database contains no production organization or keys and no model usage. The original interface labels are unchanged.

For isolation, the frontend ran on port 18704. Browser requests for the built-in backend URL `localhost:18001` were forwarded to the real isolated backend on port 18703. No API response was fabricated. This image is a local demo, not evidence of a current deployment or cost savings.
